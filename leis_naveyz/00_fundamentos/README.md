# Fundamentos do ArreioWork

## Sobre este capítulo

Os **Fundamentos** constituem a base conceitual do ArreioWork.

Antes de compreender como um Planeta é construído, como seus Habitantes interagem ou como suas Leis governam seu funcionamento, é necessário compreender **por que o ArreioWork existe**.

Este capítulo estabelece os princípios permanentes que orientam todo o ecossistema. Seu conteúdo independe de linguagem de programação, framework, sistema operacional ou infraestrutura.

Enquanto tecnologias evoluem, os Fundamentos permanecem.

---

# Objetivo

Os Fundamentos têm como objetivo estabelecer uma linguagem comum para que qualquer pessoa envolvida no desenvolvimento de software possa compreender o ArreioWork.

Isso inclui:

* Desenvolvedores;
* Arquitetos de Software;
* Analistas de Sistemas;
* Product Owners;
* UX/UI Designers;
* QA (Quality Assurance);
* DevOps;
* Gestores de Tecnologia;
* Estudantes;
* Pessoas sem formação técnica que participem da construção de soluções.

O ArreioWork considera que a compreensão de um software não deve depender exclusivamente da leitura de código.

---

# O que você encontrará aqui

Este capítulo responde perguntas fundamentais.

* O que é o ArreioWork?
* Por que ele foi criado?
* Quais problemas procura resolver?
* Quais princípios nunca podem ser violados?
* Como pensar utilizando sua linguagem?
* Quais conceitos formam seu universo?

Não apresenta detalhes de implementação.

Não ensina linguagens de programação.

Não define arquiteturas específicas.

Esses assuntos pertencem aos capítulos posteriores.

# Escopo

Os Fundamentos definem **conceitos**, não implementações.

Por esse motivo, este capítulo evita associar elementos do ArreioWork a tecnologias específicas.

Por exemplo:

* Um **Portal** não é necessariamente uma API REST.
* Um **Habitante** não é necessariamente uma classe.
* Um **Livro** não é necessariamente um banco de dados.
* Uma **Identidade** não é necessariamente um arquivo de configuração.

Cada conceito representa uma função dentro do universo. Sua implementação pode variar conforme a tecnologia utilizada.

---

# Princípios de escrita

Toda documentação dos Fundamentos segue os seguintes princípios:

* Clareza acima de complexidade.
* Conceitos antes de implementações.
* Independência tecnológica.
* Linguagem consistente em todo o ecossistema.
* Definições únicas para cada termo.
* Evolução sem perda de compatibilidade conceitual.
