📍 O que é um seletor CSS?

O seletor é o “endereço” do elemento na página.

Ele serve para localizar o elemento e executar ações como clicar, preencher ou extrair dados.
Importante: o seletor não mostra estilos, apenas identifica o elemento.

No Navyauto Blocks, você usa seletores nos campos marcados com “Seletor CSS”. Em vez de adivinhar, você pode usar o 🔍 Conversor de Elemento para gerar o seletor automaticamente.

🔍 Como usar o Conversor de Elemento novo!

✨ A ferramenta que transforma HTML em seletor pronto para usar

Basta copiar o outerHTML do elemento que você quer automatizar, colar no conversor e ele sugere os melhores seletores — classificados por estabilidade.

1
Clique em 🔍 ao lado do campo “Seletor CSS” Isso abre o Conversor de Elemento dentro do editor de blocos.
2
Obtenha o outerHTML do elemento No navegador, clique com o botão direito no elemento → Inspecionar → no DevTools, clique com o direito no nó → Copiar → Copiar outerHTML.
3
Cole no conversor e clique em “Analisar” O sistema vai extrair todos os atributos e gerar uma lista de seletores candidatos.
4
Escolha o melhor e clique em “Usar” O seletor será automaticamente preenchido no campo do bloco. Pronto, sem digitar nada!
💡 Dica: O conversor classifica os seletores como ✅ Recomendado (mais estável), 👍 Alternativo (funciona, mas com ressalvas) ou ⚠️ Evitar (pode quebrar). Prefira sempre os recomendados!

🧩 Tipos de seletores estáveis vs. frágeis

✅ Estável (recomendado)
  • [name="q"] — atributo name
  • [aria-label="Pesquisar"] — atributo acessível
  • .gLFyf — classe específica
  • #login-button — ID estável
✔️ Preferir
⚠️ Frágil (evitar se possível)
  • #APjFqb — ID dinâmico (muda a cada sessão)
  • div > span > a > button — caminho longo
  • .header > .nav > ul > li:nth-child(3) — dependente de posição
⚠️ Pode quebrar
💡 Dica de ouro: IDs como #APjFqb funcionam, mas podem mudar a cada visita. Prefira atributos como [name="q"] ou [aria-label] — eles são mais estáveis.

📋 Como copiar o outerHTML

Para usar o Conversor de Elemento, você precisa do outerHTML do elemento. Siga este passo a passo:

1
Clique com o botão direito sobre o elemento No navegador, clique no campo, botão ou texto que você quer automatizar.
2
Escolha “Inspecionar” Isso abre as Ferramentas do Desenvolvedor (DevTools) com o elemento destacado.
3
Clique com o botão direito no código destacado (no painel Elements) No DevTools, o elemento aparecerá em azul. Clique com o direito sobre ele.
4
Copiar → Copiar outerHTML No menu, vá em “Copiar” e depois “Copiar outerHTML”. Pronto! Agora cole no conversor.

📋 Regras práticas para evitar erros

  • Prefira IDs quando forem estáveis (ex: #login-btn).
  • Use classes se forem únicas e não mudarem (ex: .header-title).
  • Atributos como name, aria-label, role são os mais confiáveis.
  • Evite caminhos longos como div > span > a > button.
  • Sempre teste no Console antes de colocar no Navyauto.
  • Não use IDs gerados automaticamente (ex: #APjFqb) — eles mudam.
  • Não use seletores que dependem de posição (ex: :nth-child(3)) a menos que seja realmente necessário.

⚖️ Exemplo prático no Navyauto

❌ Frágil (pode quebrar):
{ "action": "fill", "selector": "#APjFqb", "value": "teste" }
O ID #APjFqb pode mudar a cada sessão.
✅ Estável (recomendado):
{ "action": "fill", "selector": "[name='q']", "value": "teste" }
O atributo name é estável e não muda.
