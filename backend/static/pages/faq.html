🤔 O que é o Navyauto Blocks?

É uma ferramenta visual que permite criar automações para navegador sem precisar programar. Você arrasta blocos (como "Navegar", "Preencher", "Clicar") para uma área de montagem, preenche os dados e o sistema gera um arquivo JSON que pode ser executado pelo Navyauto (ou qualquer outra ferramenta compatível com Playwright/JSON).

É ideal para quem nunca programou, mas quer automatizar tarefas repetitivas em sites.

🔍 Como faço para achar o "Seletor CSS" de um elemento?

Essa é a dúvida mais importante! Você tem duas opções dentro do sistema:

  1. Usar o Conversor de Elemento (recomendado): clique no botão 🔍 ao lado do campo "Seletor CSS". Cole o outerHTML do elemento (copiado pelo Inspecionar → Copiar outerHTML) e clique em "Analisar". O sistema vai sugerir os melhores seletores, classificados por estabilidade. Basta clicar em "Usar".
  2. Copiar manualmente: clique com o botão direito no elemento → "Inspecionar" → no DevTools, clique com o direito no nó → "Copiar" → "Copiar seletor".
💡 Dica: Prefira seletores com name, aria-label ou classes específicas. Evite IDs estranhos como #APjFqb — eles podem mudar.
🧱 O que significa cada bloco? (Navegar, Preencher, Clicar...)

Cada bloco executa uma ação específica no navegador:

  • 🌐 Navegar: Abre uma URL.
  • ✏️ Preencher: Digita um texto em um campo (input ou textarea).
  • 🖱️ Clicar: Clica em um botão, link ou qualquer elemento.
  • ⌨️ Pressionar tecla: Simula uma tecla (ex: Enter).
  • 👆 Pairar: Passa o mouse sobre um elemento (útil para menus).
  • 📋 Selecionar opção: Escolhe um item em um <select>.
  • 📊 Extrair dados: Pega um texto (ou atributo) da página e guarda numa variável.
  • 📸 Capturar tela: Tira um print da página.
  • ⏳ Esperar: Aguarda alguns segundos.
  • 🔍 Esperar elemento: Aguarda até que um elemento apareça na tela.
  • 📦 Definir variável: Cria ou altera um valor.
  • 📝 Registrar mensagem: Mostra algo no console (útil para testes).
  • 🔄 Repetir (loop): Executa um grupo de ações várias vezes.
  • ⚖️ Condição (compare): Compara valores e executa ações diferentes.
  • 🔔 Notificar: Envia uma mensagem para um webhook (ex: Discord, Slack).
📄 Para que serve o JSON que é gerado?

O JSON gerado é o script de automação que o Navyauto (ou outras ferramentas como Playwright) interpreta.

Depois de montar seu fluxo, clique em "Gerar JSON" e depois em "Baixar" para salvar o arquivo .json no seu computador. Esse arquivo pode ser carregado diretamente no sistema Navyauto para executar a automação.

⚠️ Importante: O JSON é apenas o "código" do seu fluxo. Para executá-lo, você precisa usar o Navyauto (a engine de automação) em conjunto.
🔄 O que são blocos com "dentro" (Loop e Condição)?

Blocos como "Repetir (loop)" e "Condição (compare)" são estruturas de controle. Eles têm um espaço interno onde você pode arrastar outros blocos.

  • 🔄 Repetir: Os blocos dentro dele serão executados N vezes (definidas no campo "Vezes").
  • ⚖️ Condição: Ele tem dois caminhos: "on_true" (se a condição for verdadeira) e "on_false" (se for falsa). Arraste os blocos para o caminho correto.

Para adicionar blocos dentro, simplesmente arraste da paleta para a área dentro deles.

🛑 Meu fluxo não funcionou. O que fazer?

A maioria dos erros acontece por dois motivos:

  1. Seletor errado ou frágil: O elemento pode ter mudado de nome ou não estar visível. Use o Conversor de Elemento (🔍) para gerar um seletor estável (recomendado) e tente novamente.
  2. A página não carregou completamente: Adicione um bloco "Esperar elemento" (com o seletor do elemento principal) antes de interagir com a página, para garantir que tudo está pronto.
💡 Dica: Use o bloco "Registrar mensagem" em pontos-chave para entender onde a automação está parando.
💾 Posso salvar e compartilhar meu trabalho?

Sim! O sistema é 100% front-end (roda no seu navegador), então tudo fica apenas na sua máquina.

  • Salvar: Clique em "Baixar" na área de saída. Isso vai gerar um arquivo .json com seu fluxo.
  • Compartilhar: Você pode enviar esse arquivo .json para outra pessoa, que pode abrir o mesmo editor e carregar (basta arrastar os blocos manualmente seguindo o JSON, ou usar a ferramenta para gerar novamente).
  • Limpar: Use o botão "Limpar tudo" para recomeçar do zero.
🖥️ Preciso instalar alguma coisa para usar?

Não! O Navyauto Blocks é um único arquivo HTML que roda diretamente no seu navegador (Chrome, Edge, Firefox, etc.).

Basta baixar o arquivo blockgenerator.html e abrir com duplo clique. Não precisa de servidor, internet (depois de carregar) ou instalação.

✅ Pronto para usar: Se você está vendo esta página, já pode abrir o editor e começar a montar seus fluxos.
🔧 Como faço para testar se o seletor está certo?

Existem duas formas práticas:

  1. Usando o campo "Teste seu seletor" no Manual: Digite o seletor e veja a validação simulada.
  2. No navegador (Console): Pressione F12 para abrir o DevTools, vá na aba "Console" e digite
    document.querySelector('seu_selector_aqui')
    Se retornar o elemento (ex: <input>), está correto. Se retornar null, está errado.
🎯 O que significa "Recomendado", "Alternativo" e "Evitar" no conversor?

O Conversor de Elemento classifica os seletores com base na estabilidade (chance de continuarem funcionando no futuro):

  • ✅ Recomendado: Atributos como name, aria-label ou IDs estáveis. Dificilmente mudam.
  • 👍 Alternativo: Classes específicas ou combinações. Funcionam, mas podem ser menos únicos.
  • ⚠️ Evitar: IDs gerados dinamicamente (ex: #APjFqb) ou caminhos longos. Mudam com frequência ou são frágeis.

Regra de ouro: Sempre escolha um seletor da categoria "Recomendado" quando possível.
