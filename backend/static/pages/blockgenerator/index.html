🔍 Conversor de Elemento → Seletor

Cole o HTML completo (outerHTML) do elemento que você quer automatizar. O sistema vai analisar e sugerir os melhores seletores CSS.

📌 Como obter o outerHTML:
  1. Clique com o botão direito no elemento → Inspecionar
  2. No DevTools, clique com o botão direito no nó destacado → Copiar → Copiar outerHTML
  3. Cole o conteúdo abaixo e clique em "Analisar"
💡 Exemplo: <input type="text" name="q" id="APjFqb" class="gLFyf">
